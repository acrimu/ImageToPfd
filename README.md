# Paperstack — Images to PDF

An offline desktop app that combines PNG, JPG, WebP, BMP, and TIFF images into one PDF.

## Start

1. Install Python 3.10 or newer.
2. Run `pip install -r requirements.txt` once.
3. Double-click `run_app.bat`.

Add images, arrange their order, choose the page settings, and select **Create PDF**. Double-click an image to preview it.
